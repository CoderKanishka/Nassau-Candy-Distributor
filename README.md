# 🍬 Nassau Candy Distributor

## 📊 Sales, Profitability & Business Intelligence Analysis

An end-to-end data analytics and business intelligence project based on the Nassau Candy Distributor dataset.

The project covers data preparation, exploratory data analysis, profitability analysis, interactive Streamlit dashboard development, and Power BI visualization.

---

## 🎯 Project Objectives

- Analyze sales and profitability performance
- Identify top-performing products
- Analyze regional sales performance
- Compare division-wise profitability
- Analyze customer sales contribution
- Track monthly sales trends
- Calculate key business KPIs
- Build interactive dashboards for business decision-making
